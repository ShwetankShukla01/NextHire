# NextHire

A full-stack MERN Job Portal connecting recruiters and job seekers.

## Features

- JWT Authentication
- Role Based Login
- Recruiter Dashboard
- Student Dashboard
- Admin Dashboard
- Job CRUD
- Apply Jobs
- Resume Upload
- Search & Filter
- Responsive UI

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- JWT
- Tailwind CSS
